helm install mydb bitnami/mysql --wait : wait time is 5 mins
helm install mydb bitnami/mysql --wait --timeout 5m10s
helm install mydb bitnami/mysql --wait --timeout 5m10s --atomic --force --cleanup-on-failure
wait is used to force helm wait for 5 mins (or else timeout is given) and in that time k8s pods shall be sucessfully up and running
force : by default helm restarts only modified pods and not all , force can recreate all ut will have downtime
--cleanup-on-failure: if error occurs it clean up the revision/version data in secrets etc
